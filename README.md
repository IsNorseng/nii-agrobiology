# НИИ Агробиологии СССР

Поливайте, кормите и брейте пиксельный овощ. Комиссия наблюдает.

Карманный тамагочи для Android в стилистике старых портативных игр. Выберите подопытный образец из пяти претендентов, доведите его до 30 см и получите комиссионное заключение. После измерения эксперимент продолжается, а рекорд и последний акт сохраняются на устройстве.

## Установка

[Скачать APK v0.3](downloads/NII-Agrobiologii-USSR-v0.3.apk?raw=1) для Android 6.0 и новее. Откройте скачанный файл на смартфоне.

## Сборка

Нужны Windows, PowerShell, JDK 21 и Android SDK с пакетами `platforms;android-36.1` и `build-tools;36.1.0`.

```powershell
.\build.ps1
```

Скрипт использует `JAVA_HOME` и `ANDROID_HOME`. Пути можно передать явно через `-Jdk` и `-Sdk`. APK без подписи появится в `build/agrobiology-unsigned.apk`.

Для установочной сборки укажите собственное хранилище ключей, псевдоним ключа и задайте пароль хранилища в переменной окружения `AGROBIOLOGY_KEYSTORE_PASSWORD`.

```powershell
.\build.ps1 -Keystore .\my-key.p12 -KeyAlias agrobiology
```

Подписанный файл появится в `build/agrobiology.apk`. Android принимает обновления поверх установленной версии, когда обе сборки подписаны одним ключом.
